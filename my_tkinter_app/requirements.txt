# ============================================================
# FORENXAI - PYTHON REQUIREMENTS + SETUP GUIDE
# ============================================================
#
# IMPORTANT:
# This file installs PYTHON dependencies only.
#
# ForenXAI prefers two external programs that pip CANNOT
# install:
#
#   1. Java JDK 8
#   2. CICFlowMeter v4
#
# Since the PCAP fallback was added these are no longer required
# to get a working install. If CICFlowMeter v4 is absent, the
# pure-Python extractor at the bottom of this file takes over
# automatically and PCAP upload still works, with the two limits
# documented there. Install CICFlowMeter v4 when you can: it is
# the reference implementation the model was trained against.
#
# Follow the setup guide below from TOP to BOTTOM after cloning
# the repository.
#
# ============================================================
# STEP 1 - CLONE THE REPOSITORY
# ============================================================
#
# Open PowerShell and run:
#
#   git clone <YOUR-GITHUB-REPOSITORY-URL>
#   cd ForenXAI-v2
#   cd my_tkinter_app
#
# If you already cloned the repository:
#
#   cd ForenXAI-v2
#   git pull
#   cd my_tkinter_app
#
#
# ============================================================
# STEP 2 - CHECK PYTHON
# ============================================================
#
# ForenXAI is a Python desktop application.
#
# Check Python:
#
#   python --version
#
# Check pip:
#
#   pip --version
#
# If both commands work, continue.
#
#
# ============================================================
# STEP 3 - CREATE A VIRTUAL ENVIRONMENT (RECOMMENDED)
# ============================================================
#
# From the "my_tkinter_app" directory:
#
#   python -m venv .venv
#
# Activate it:
#
#   .\.venv\Scripts\Activate.ps1
#
# If PowerShell blocks activation, run PowerShell as needed or
# use the following instead:
#
#   .\.venv\Scripts\activate.bat
#
# After activation, the terminal should show something similar
# to:
#
#   (.venv) PS C:\...\my_tkinter_app>
#
#
# ============================================================
# STEP 4 - UPGRADE PIP
# ============================================================
#
# Run:
#
#   python -m pip install --upgrade pip
#
#
# ============================================================
# STEP 5 - INSTALL THIS FILE
# ============================================================
#
# Run:
#
#   pip install -r requirements.txt
#
# This installs the Python packages required by the current
# ForenXAI application.
#
#
# ============================================================
# STEP 6 - VERIFY PYTHON PACKAGES
# ============================================================
#
# Run these commands one at a time:
#
#   python -c "import numpy; print('NumPy OK:', numpy.__version__)"
#   python -c "import pandas; print('Pandas OK:', pandas.__version__)"
#   python -c "import sklearn; print('scikit-learn OK:', sklearn.__version__)"
#   python -c "import joblib; print('joblib OK')"
#   python -c "import shap; print('SHAP OK:', shap.__version__)"
#   python -c "import matplotlib; print('Matplotlib OK:', matplotlib.__version__)"
#   python -c "import tkinterdnd2; print('tkinterdnd2 OK')"
#   python -c "import xgboost; print('XGBoost OK:', xgboost.__version__)"
#   python -c "import catboost; print('CatBoost OK:', catboost.__version__)"
#
# If all commands print OK, the Python environment is ready.
#
#
# ============================================================
# STEP 7 - CHECK TKINTER
# ============================================================
#
# Tkinter normally comes with the Windows Python installation.
# It is NOT installed through pip.
#
# Test it:
#
#   python -c "import tkinter; print('Tkinter OK')"
#
# If this fails, repair/reinstall Python with Tcl/Tk support.
#
#
# ============================================================
# STEP 8 - INSTALL JAVA JDK 8
# ============================================================
#
# CICFlowMeter v4 requires Java.
#

#
# After installation, close and reopen PowerShell, then check:
#
#   java -version
#   javac -version
#
# Both should report Java 8 / JDK 8.
#
# IMPORTANT:
# JDK is required, not only a JRE.
#
#
# ============================================================
# STEP 9 - INSTALL CICFLOWMETER v4
# ============================================================
#

#
#   C:\Tools\CICFlowMeter\
#
# The important executable should be:

#   C:\Tools\CICFlowMeter\installed\CICFlowMeter-4.0\bin\cfm.bat

#
#
# ============================================================
# STEP 10 - VERIFY CICFLOWMETER FILES
# ============================================================
#

#
#   dir C:\Tools\CICFlowMeter\installed\CICFlowMeter-4.0\bin\cfm.bat
#
# Check the native jNetPcap libraries:
#
#   dir C:\Tools\CICFlowMeter\installed\CICFlowMeter-4.0\lib\native
#
# The native directory should contain the Windows DLL files,

#
# ============================================================
# STEP 11 - CREATE CICFLOWMETER TEST FOLDERS
# ============================================================
#
# Run:

#   New-Item -ItemType Directory -Force C:\Tools\CICFlowMeter\test
#   New-Item -ItemType Directory -Force C:\Tools\CICFlowMeter\test-output
#

#
#   C:\Tools\CICFlowMeter\test\test.pcap

# IMPORTANT:
# The currently tested CICFlowMeter v4 command expects the
# INPUT DIRECTORY and OUTPUT DIRECTORY:
#
#   .\installed\CICFlowMeter-4.0\bin\cfm.bat "C:\Tools\CICFlowMeter\test" "C:\Tools\CICFlowMeter\test-output"

# Do NOT test using only the individual .pcap path.

# ============================================================
# STEP 12 - VERIFY CICFLOWMETER GENERATES A CSV

# ------------------------------------------------------------
# NARRATION AND THE CITED-SOURCE CORPUS -- both required
# ------------------------------------------------------------
#
# requests is how the app talks to the local Ollama server that
# writes the three XAI panels. Without it every panel falls back
# to its deterministic summary; the app still runs, but no
# sentence is model-written.
#
# pypdf re-extracts a PDF whenever the extracted-text cache is
# missing. That extracted text is what source_guard checks each
# quoted passage against, so without pypdf and without the cache
# every quote fails verification and its document is quarantined
# -- the panels then render with their citations withheld.
#
# Ship the .cache/ folder alongside the PDFs (see README) and
# neither cost is paid at run time: verification of the whole
# corpus is 0.68 ms once memoised.

requests==2.34.2
pypdf==6.17.0

# ------------------------------------------------------------
# PCAP FALLBACK -- read this before skipping it
# ------------------------------------------------------------
#
# These two let ForenXAI convert a PCAP without CICFlowMeter v4.
# CICFlowMeter v4 is still preferred and is used automatically
# when installed: it is the reference implementation the model
# was trained against, and it has no memory limit.
#
# The fallback exists because CICFlowMeter v4 needs jnetpcap
# native libraries that frequently cannot be installed on
# Windows, and without it the PCAP upload path does not work at
# all.
#
# Two limits apply when the fallback is what runs:
#
#   * It holds a flow's packets until that flow closes, so a
#     dense capture is refused with instructions rather than
#     exhausting memory. Around 600,000 packets is the ceiling.
#   * Activity, bulk and subflow columns sit on slightly
#     different boundaries than v4 uses.
#
# Which engine produced a flow table is recorded in
# flow_extraction.json beside the CSV, and shown in the Flow
# Summary panel.
#
# scapy is pinned at 2.7 because it renamed the session hook
# that cicflowmeter 0.2.0 targets; services/pyflow_extractor.py
# works around that. An older scapy also works. Re-check a newer
# one against test_panels_suite.py section I.

# ------------------------------------------------------------
# PACKAGING -- only if you are building the .exe
# ------------------------------------------------------------
#
# build_exe.py encodes the flags. Do not reconstruct them: one of the
# three failures it works around only appears when a model is loaded,
# because services/model_input.py is imported by joblib at unpickle time
# and nothing imports it statically.

pyinstaller==6.22.2

cicflowmeter==0.2.0
scapy==2.7.0
